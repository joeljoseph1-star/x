# AgroSpace Xcel — FieldShift Website

This is a GitHub Pages-ready static website for NASA Space Apps Challenge 2026.

## Upload to GitHub Pages

1. Extract this ZIP.
2. Open the extracted folder.
3. Upload **index.html**, **styles.css**, **script.js**, and the entire **images** folder to the root of your GitHub repository.
4. In GitHub: Settings → Pages → Deploy from a branch → select `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish.
